variables. The variables describe the subway line, station name and
coordinates, routes served, entry permission, vending availability,
entrance type, and ADA compliance. I standardized the column names,

## Tidy the route information

``` r
subway_long_df =
  subway_df |>
  mutate(
    across(starts_with("route"), as.character)
  ) |>
  pivot_longer(
    cols = starts_with("route"),
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name",
    values_drop_na = TRUE
  ) |>
  mutate(
    route_number = as.integer(route_number)
  )

n_a_stations =
  subway_long_df |>
  filter(route_name == "A") |>
  distinct(line, station_name) |>
  nrow()

n_a_ada_stations =
  subway_long_df |>
  filter(route_name == "A", ada == TRUE) |>
  distinct(line, station_name) |>
  nrow()
```

I converted the route columns to character variables and reshaped them
into route_number and route_name. Missing route entries were omitted.
Each row now represents one route served by an entrance/exit record. The
resulting dataset contains 4270 rows and 10 columns.

There are 60 distinct stations serving the A train, of which 17 are ADA
compliant.

The combined dataset contains 1269 dumpster collection records and 15
variables from three trash wheels. Key variables include collection
date, trash weight in tons, volume in cubic yards, and counts of items
such as plastic bottles and cigarette butts. The wheel variable
identifies the source of each record. I selected the relevant Excel
ranges, standardized column names and data types, removed rows without
dumpster numbers, and combined the three datasets. Sports-ball counts
were rounded and stored as integers. Variables absent from a source
worksheet are recorded as missing after combining.

Across the available records, Professor Trash Wheel collected 294.96
tons of trash. Gwynnda collected 1.812^{4} cigarette butts in June 2022.
